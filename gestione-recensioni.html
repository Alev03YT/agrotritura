Backup e pubblicazione

Per visualizzarle online devi esportare il file delle recensioni approvate e caricarlo nel repository GitHub come data/recensioni.json. Non viene pubblicato automaticamente.

Per raccogliere nuove recensioni puoi inviare al cliente la pagina pubblica dopo la consegna. Usa dati autorizzati: le valutazioni non vanno modificate per migliorarne il tono.
